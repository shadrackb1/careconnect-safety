# CareConnect Safety

Real-time care coordination for parents and caregivers — activity logs, live location, emergency alerts, and handoff notes in a mobile-first PWA.

## Features

- Live activity feed (meals, meds, naps, incidents)
- GPS check-ins and geofenced alerts
- Emergency SOS with caregiver broadcast
- Multi-caregiver handoff notes
- Offline-tolerant local cache, sync when online

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Firebase (Auth + Firestore)
- Capacitor (Android)
- Leaflet maps
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```
